# KVX Portal Frontend

A React + Vite frontend for the KVX Portal application.

## Requirements

- Node.js 18 or newer
- npm

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Scripts

- `npm run dev` — start Vite development server
- `npm run build` — build production assets
- `npm run lint` — run ESLint across project files
- `npm run preview` — locally preview production build

## Notes

- Vite is pinned to `5.4.21`
- `@vitejs/plugin-react` is pinned to `4.7.0`
- Node >= 18 is required for the current runtime and Vite compatibility
